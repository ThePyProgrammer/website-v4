Argus is a simulation-native robotics research workbench for developing, visualizing, and evaluating multi-robot autonomy. Built around MuJoCo, it connects simulated robot swarms to a real-time browser-based command center, integrating modular SLAM backends, 3D perception pipelines, autonomous exploration, coordination strategies, and locomotion controllers. Argus enables researchers to observe multiple robots simultaneously, inspect shared point-cloud maps, issue navigation commands, and evaluate algorithms through reproducible benchmarking environments. Argus provides an experimental platform for investigating how multiple embodied agents can perceive, navigate, and coordinate within shared environments.
