UniCV is a Python library designed to unify deep learning models across different computer vision tasks and visual representations. UniCV introduces a standardized interface for working with models that process RGB images, depth maps, point clouds, meshes, and 3D Gaussian splats. Through composable model abstractions, UniCV enables developers to integrate and connect perception algorithms without repeatedly rewriting preprocessing, inference, and output-handling pipelines. The library aims to simplify experimentation with modern computer vision architectures and support the development of interoperable, multimodal 3D perception systems.
