AI Traffic Controller (AITC) is a desktop application for monitoring and coordinating multiple AI coding agents working within the same codebase. Inspired by real-world air traffic control, it visualizes active agents as aircraft navigating a shared repository, with a live radar interface mapping their activity across files and dependencies. The application detects conflicting file modifications, provides three-way merge tools, manages agent permissions and approval requests, and centralizes agent communication and session history. AITC aims to make parallel agentic software development more observable, manageable, and less prone to accidental code conflicts.
